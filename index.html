04 / Launch

Recommended setup guide

1. Install a local model runner

Install Ollama if your device supports it, then choose a model that fits available memory.

ollama pull qwen2.5-coder

2. Scaffold an app

Choose an app builder, configure a supported model provider, and generate a small starter project.

3. Review and test

Inspect every change, run tests and commit working versions to Git.

pip install aider-chat

Security: Never paste API keys into public repositories or frontend code. Use server-side environment variables or a secure secrets manager.
