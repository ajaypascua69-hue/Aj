BUILD YOUR OWN ANDROID APP

LEO App Builder

Create a starter project locally, export its source ZIP, then use the free Android build workflow.

This builder uses local starter templates, not an AI model. Complex custom features still need code development.

Build an installable APK

  1. Extract the ZIP.
  2. Upload its project files into the generated-app folder in the AJ repository.
  3. Open GitHub → Actions → Build LEO AI Android APK → Run workflow.
  4. Select generated-app, enter the app name and package ID, and run it.
  5. Download the APK from the successful workflow's Artifacts.

GitHub Actions has free usage limits. The debug APK is for direct installation and testing. Play Store publication requires a properly signed release.
