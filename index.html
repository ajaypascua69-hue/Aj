03 / Build safely

A reliable AI coding workflow

1

Describe the task

Write down the feature, expected behavior and how you will know it works.

2

Make a small change

Ask your coding assistant to explain its plan and change only the files needed.

3

Test and review

Run the app, inspect the changes, test on mobile and keep a working Git commit.

05 / Get started

Starter commands

These commands are examples for a computer with the required software installed. They do not run on this website.

Download a coding model with Ollama

Choose a model tag that is currently available and suitable for your hardware.

ollama pull qwen2.5-coder

Install Aider with pip

Use a Python environment on your development computer.

python -m pip install aider-chat

Keep your API keys private. Never put secret keys in index.html, app.js, or any public GitHub repository. A real public-facing API integration needs a secure backend that keeps keys on the server.
