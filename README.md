# AJ — AI Development Hub

AJ is a directory and learning hub for discovering AI app builders, coding assistants, models, and practical development workflows.

**Live website:** https://ajaypascua69-hue.github.io/Aj/

## Features

- Responsive layout for desktop and mobile
- Searchable and filterable developer-tool directory
- Curated links to official project and model pages
- Starter commands with copy buttons
- Practical guidance for choosing tools and reviewing AI-generated code
- Security reminders for API keys and public repositories

## Run locally

This is a static website. No build step or package installation is required.

1. Download the repository from GitHub.
2. Extract the downloaded archive.
3. Open `index.html` in a browser, or serve the folder with a static web server.

## Project files

- `index.html` — page structure and content
- `style.css` — responsive styling
- `app.js` — search, filters, navigation, copy interactions, install prompt, and service-worker registration
- `manifest.webmanifest` — installable web-app metadata
- `service-worker.js` — offline app-shell caching
- `icon.svg` — AJ app icon
