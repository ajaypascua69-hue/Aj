# AJ — Open Source AI Development Hub

AJ is a community-friendly directory and learning hub for discovering AI app builders, coding assistants, models, and practical development workflows.

**Live website:** https://ajaypascua69-hue.github.io/Aj/

## Features

- Responsive layout for desktop and mobile
- Searchable and filterable developer-tool directory
- Curated links to official project and model pages
- Starter commands with copy buttons
- Practical guidance for choosing tools and reviewing AI-generated code
- Security reminders for API keys and public repositories

## Run locally

This is a static website. No build step or package installation is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/ajaypascua69-hue/Aj.git
   ```
2. Open the `index.html` file in a browser, or serve the folder with any static web server.

## Project files

- `index.html` — page structure and content
- `style.css` — responsive styling
- `app.js` — search, filters, navigation, and copy interactions
- `LICENSE` — MIT License

## Contributing

Contributions are welcome.

1. Fork this repository.
2. Create a branch for your change.
3. Make a focused improvement.
4. Test the site on mobile and desktop.
5. Open a pull request describing what changed and how you tested it.

Please keep links pointed to official sources where possible, verify tool information before adding it, and avoid committing secrets or API keys.

## Security

Never commit API keys, passwords, access tokens, or other secrets. A public static website cannot safely keep private API credentials. Real AI API integrations should use a backend service that stores credentials securely.
